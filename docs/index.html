Kalos Gym System — live demo

A QR membership card, attendance streaks, renewal reminders and an owner dashboard for a calisthenics gym — built on Google Sheets and Apps Script. This demo runs the real server code in your browser against an in-memory sheet of invented students.

Synthetic data · nothing is saved · resets on reload

StudentPlanStatusPhone (for check-in)

To try check-in: press Simulate scanning it, type one of the phone numbers above, and a streak update appears. Without the rotating code the server answers “scan the door QR first”.

What to look at

  1. Presence proof: the check-in rejects requests without a valid, recent door code (HMAC of a one-minute window).
  2. Streak logic: only business days count, holidays are skipped, and a 3×/week plan follows weekly rules.
  3. Owner numbers: revenue split per partner, renewal rate with a 10-day grace window, attendance by hour.
